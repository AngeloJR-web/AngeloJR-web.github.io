Cofre de senhas

VaultCore

Rust · Tauri · React · TypeScript

Gerenciador de senhas para Windows, sem conta e sem nuvem. O cofre fica cifrado no seu disco e o app se atualiza sozinho com pacotes assinados.

Master

Dashboard

Tauri · Rust · React · Three.js

App desktop para mestres de RPG conduzirem campanhas do sistema Ordem Paranormal, com tudo que a sessão precisa em uma tela só.

Catálogo de doramas

DoramaRank

Electron · JavaScript · SQLite · Chart.js

App desktop para acompanhar séries asiáticas. Ele busca pôster, sinopse e elenco no TMDB e guarda tudo em um banco local.

Carteira de fundos

FII Tracker

Tauri · Rust · JavaScript · Chart.js

App desktop para acompanhar fundos imobiliários, com cotações da B3 atualizadas em segundo plano e dados cifrados no seu computador.

Controle do cartão

Parcelas

Electron · React · TypeScript · SQLite

App desktop para controlar gastos no cartão de crédito: registra compras, divide as parcelas e mostra o que vem em cada fatura.
